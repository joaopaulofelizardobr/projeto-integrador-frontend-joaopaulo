# Projeto Integrador Frontend

Este projeto apresenta um site voltado para conteudos e informacoes sobre a fe catolica.
A plataforma pretende disponibilizar conteudos relacionados a Igreja Catolica, a Biblia e a espiritualidade crista.
O objetivo e oferecer um espaco acessivel e organizado para pessoas que desejam conhecer ou aprofundar sua fe.
